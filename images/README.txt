INSTRUKSI LOGO
==============

Silakan simpan logo HME UNINUS Anda di folder ini dengan nama:
logo-hme.png

Logo akan otomatis muncul di navbar website.

Ukuran yang disarankan:
- Format: PNG (dengan transparansi background)
- Ukuran: Minimal 200x200px
- Ukuran optimal: 300x300px atau lebih besar

Logo akan otomatis di-resize oleh CSS menjadi 45px tinggi.
